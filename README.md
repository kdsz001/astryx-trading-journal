# 交易日志 · Astryx Showcase

用 Meta [Astryx](https://github.com/meta/astryx) 设计系统做的「交易日志」示例仪表盘。

> 全部为**示例数据**，非真实持仓。数据只存在浏览器 `localStorage`。

## Live

https://kdsz001.github.io/astryx-trading-journal/

## Dev

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Stack

- React 19 + Vite + TypeScript
- `@astryxdesign/core` + Stone theme（自定义 fintech 强调色）
